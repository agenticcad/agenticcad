Tutorials · simulated sessions

Watch it work. Then scrub it.

Each tutorial replays a real session: what you type, what the agent says, the tools it calls, the code it writes, and the model after every rebuild. The meshes and toolpaths were generated by the kernel for each step, so what you see is what the app produces. Nothing here calls a server.

ABOUT

Controls: space play/pause, ← → step, click the progress bar to jump. The 3D view is live: drag to orbit, scroll to zoom. To follow along in the real app, download it for macOS or Windows.
