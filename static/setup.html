One more thing: Claude Code

AgenticCAD's agent runs on Claude Code, Anthropic's command-line tool. It is not bundled with this app, so install it once and sign in with your Claude account (or an API key). AgenticCAD finds it automatically afterwards.

1 · Install Claude Code

macOSWindowsLinux

In Terminal:

curl -fsSL https://claude.ai/install.sh | bash

Or brew install --cask claude-code. Installs to ~/.local/bin/claude.

In PowerShell:

irm https://claude.ai/install.ps1 | iex

Installs claude.exe under %USERPROFILE%\.local\bin. The npm install (claude.cmd) is not usable from a desktop app; use the installer above.

In a terminal:

curl -fsSL https://claude.ai/install.sh | bash

Official instructions: docs.anthropic.com → Claude Code → Set up. Claude Code is Anthropic's software under Anthropic's terms; AgenticCAD is a separate program that talks to it.

2 · Sign in

checking sign-in…

Option A — your Claude account. Open a terminal, run claude, and choose Log in (a browser window opens). A Claude Pro or Max subscription works. AgenticCAD reuses that login and never sees your password. The app cannot show that prompt itself because it runs Claude Code headless, which is why an expired login shows up here rather than as a pop-up. If you were logged in before, the session simply expired: run claude again.

Option B — an API key. Paste an Anthropic Console key; it is stored in settings.json in your data folder (readable by you only) and passed to Claude Code, never to anyone else.
