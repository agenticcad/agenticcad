One more thing: Claude Code

AgenticCAD's agent runs on Claude Code, Anthropic's command-line tool. It is not bundled with this app, so install it once and sign in with your Claude account (or an API key). AgenticCAD finds it automatically afterwards.

1 · Install Claude Code

macOSWindowsLinux

In Terminal:

curl -fsSL https://claude.ai/install.sh | bash

Or brew install --cask claude-code. Installs to ~/.local/bin/claude.

In PowerShell:

irm https://claude.ai/install.ps1 | iex

Installs claude.exe under %USERPROFILE%\.local\bin. The npm install (claude.cmd) is not usable from a desktop app; use the installer above.

In a terminal:

curl -fsSL https://claude.ai/install.sh | bash

Official instructions: docs.anthropic.com → Claude Code → Set up. Claude Code is Anthropic's software under Anthropic's terms; AgenticCAD is a separate program that talks to it.

2 · Sign in

Run claude once in a terminal and follow the login prompt. A Claude Pro or Max subscription works; so does an Anthropic Console account with an API key (claude asks which). AgenticCAD reuses that login; it never sees your password.

Prefer an API key without the login flow? Set ANTHROPIC_API_KEY in your environment before starting AgenticCAD.
