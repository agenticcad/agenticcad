# Security

AgenticCAD runs a local server that executes design scripts (Python) and an AI agent with tools on your
machine. Run it on trusted networks only; it has no authentication of its own yet.

To report a vulnerability, please use GitHub's private vulnerability reporting on this repository
("Report a vulnerability" under the Security tab) rather than a public issue, or email
morzel@prodevelop.com.au. We'll acknowledge within a few days.

Please do not include API keys, tokens or personal data in issues, PRs or design files.
