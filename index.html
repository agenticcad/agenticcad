How it works

The model is the script. The agent is the modeller.
You are the one pointing.

There is no feature tree to fight and no hidden state. Every design is a build123d script that the kernel executes; every change, by chat or by hand, is a change to that script.

01

Say what you want

“60 × 40 × 8 plate, four Ø5 holes 8 mm from the corners, a Ø20 boss with an Ø8 bore.” Attach a photo or a napkin sketch if you have one. The agent writes the code with named dimensions.

02

Point at it

Click a face, an edge or a body and it becomes a chip on your message, with its exact type, centre, normal and size. The agent selects that same face in code, not a guess.

03

Tweak, cut, ship

Press/pull, holes, fillets and sketches from the ribbon are written into the same script. Then CAM: adaptive roughing, tabs, drilling, G-code checked against your machine.

Features

    
Everything a small shop needs, in one script.

    

      
Exact B-rep, not triangles
Planes, cylinders, cones, spheres, tori and B-splines from OCCT. The display mesh has exact per-vertex normals; STEP export is analytic; STL is tessellated only at export, at the tolerance you choose.

      
Design as script
A design is a build123d file with named parameters. The Design tab exposes them as fields; rename, delete, add bodies and sketches are AST rewrites of that file. Undo steps through builds.

      
Sketches on any face
Select a face, press K: rectangles, circles, polygons and slots with grid snap. Stored as an editable block that is also a normal Sketch the agent can extrude, cut or revolve.

      
Fusion-style ribbon, code-backed
Box, cylinder, sphere, press/pull with a drag handle, holes (plain, counterbored, tapped), fillet, chamfer, shell, move. Each one becomes an expression on the body in the script and a note to the agent.

      
ISO threads
Tap drill, clearance, hex and socket heads, nuts and washers from the tables. tap(part, "M4", …) cuts the hole, registers the thread, and drawings call it out as M4×0.7.

      
Constant-engagement adaptive
Front-offset HSM clearing: the tool never exceeds its target engagement angle, with helix entry, engagement-aware feed in corners, rest machining from a previous tool, and an independent audit in the test suite.

      
GRBL post, machine-checked
Machines with travel, feeds, spindle range and tool-change policy; tools with feeds and stepdowns. G2/G3 arc fitting, tabs, lead arcs, pecking, feeds and speeds for 13 materials. Warnings before you press run.

      
Shop drawings
Third-angle front, top, right and iso with hidden lines, overall dimensions, hole callouts and a lettered hole table, title block with mass and scale. SVG per body plus DXF.

      
First-class part library
Parametric script parts and exact STEP parts with thumbnails and tags. Insert from the Browser, save any body to it, and the agent searches it before modelling a standard part.

      
Measure that snaps
Vertex, edge, then face snapping with a live readout: lengths, radii and sweeps, distances with closest points drawn, angles between lines and planes, hole spacing, mass and centre of mass, clearance between bodies.

      
Choose the model, plug in MCP
Settings for the Claude model, effort, max steps, thinking summaries, web tools, standing instructions and MCP servers (stdio, http, sse) with live connection status. Restart the session in place.

      
Tested, and evaluated
73 unit and API tests run in seconds with no Claude calls. 13 agent evals run the real agent headless and grade geometry, programs and answers deterministically, with cost and steps per case.

    

  






  

    

      

        
Manual, still code

        
“I just want to tweak it.”

        
Sometimes you know exactly what you want and don't want to say it. The ribbon works like a desktop CAD tool: pick, type a number, ↵. A command dialog walks you through each tool with a live prompt, chips for what you picked and unit fields. Under the hood the operation is appended to the body's expression in the script, so it is undoable, reproducible and visible to the agent.

        
_plate = plate.part
_plate2 = _plate + extrude(_plate.faces().sort_by_distance((7, 0, 19))[0], amount=5, dir=(0, 0, 1))
_plate3 = tap(_plate2, "M4", at=(18, 0, 4), depth=6, axis=(0, 0, -1))
result = {"Plate": _plate3.fillet(2, [*_plate3.faces().sort_by_distance((7, 0, 24))[0].edges()])}

CAM · GRBL

        
Ask for a program. Get real toolpaths.

        
CAM is a second script per design, written by the agent against a small, honest API: section, holes, stock_minus from the exact B-rep; face, contour, pocket, adaptive, drill, parallel3d for the cuts. The post checks travel, spindle range, feeds and depth against the machine you picked.

Get started

        
Runs on your machine, talks to your Claude.

        
Python 3.12, one virtualenv, one process. The agent uses your Claude Code login, or an ANTHROPIC_API_KEY. Nothing leaves your machine except the conversation.

        
1Python file per design
20agent tools
73unit tests
13graded agent evals

      

      


# clone, install, run
git clone https://github.com/agenticcad/agenticcad.git
cd agenticcad
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python server.py        # → http://127.0.0.1:8765

# tests (no Claude calls) and agent evals
.venv/bin/python -m pytest -q
.venv/bin/python evals/run.py
